# YONOD 学习笔记

## 项目概览

- **一句话描述**：YONOD 是一个有机合成反应预测平台；它把反应物、试剂等列转为分子描述符，再在统一的外层交叉验证中比较 RF、XGBoost、LightGBM、SVM 与 AutoGluon 等回归模型。
- **技术栈**：Python、pandas、NumPy、scikit-learn、RDKit、XGBoost、LightGBM、AutoGluon；部分描述符还依赖 PyTorch / Transformers。
- **项目类型**：面向化学反应收率、选择性或能量等连续目标的命令行建模与报告工具。

## 架构与模块

### `main.py` 与 `yonod.py`

- **职责**：分别提供命令行批处理入口和交互向导；读取 CSV、指定标签/SMILES/类别列、组织交叉验证并落盘报告。
- **关键文件**：`main.py`、`yonod.py`。
- **对外接口**：`python main.py --csv ... --label-col ... --smiles-cols ...`，或直接运行 `python yonod.py`。

### `yonod/descriptors/` 与 `yonod/features/`

- **职责**：从 SMILES 或显式条件列构造特征，例如 MFP、OHE、DFT、SOAP、PhysChem、Morgan 等。
- **关键文件**：`yonod/descriptors/`、`yonod/features/`。
- **重要边界**：OHE 必须在每个训练折单独拟合，不能用验证折的类别信息；不同描述符和不同样本总体不能直接混合比较。

### `yonod/models/`

- **职责**：封装 RF、XGBoost、LightGBM、SVM、AutoGluon 等训练/预测接口。
- **关键文件**：`yonod/models/rf_model.py`、`xgb_model.py`、`lightgbm_model.py`、`svm_model.py`、`autogluon_model.py`。

### 指标与报告

- **职责**：通用入口 `main.py` 对每个外层折计算 R²、RMSE、MAE，并输出其均值和标准差；本轮严格 5×5 静态矩阵脚本还逐折计算 Kendall τ。
- **关键文件**：`main.py`、`scripts/run_static_descriptor_model_matrix.py`、`scripts/run_static_descriptor_autogluon_matrix.py`、`yonod/universal/report.py`。
- **重要边界**：历史通用 HTML/Markdown 报告中的加权分数只用 R²/RMSE/MAE 做展示性推荐；它不是本轮 AutoGluon–RF 严格比较的统计结论，也不应把四项指标压成一个无条件的“强弱分”。

## 核心数据流

```text
CSV（反应组分、条件列、实验收率 y）
  -> 描述符/特征构造
  -> 外层 5 折或重复 5×5 划分
  -> 每一折：仅用训练折拟合 -> 对该折验证样本预测
  -> y_true 与 y_pred 逐折计算 RMSE / R² / MAE / Kendall τ
  -> 25 折 mean ± std、逐折预测与成对差值
  -> 同 population、同 descriptor、同 split 的模型配对比较
```

## 设计说明

### 指标之前，先确认“能不能比”

四个指标回答的是不同问题，**不能先把它们合成一句“模型更强”再回头找依据**。在本项目中，能进入正式比较的两种模型必须至少共享：

1. 相同的数据总体（`population_id`）与相同的目标单位；
2. 相同描述符；
3. 相同 repeat、fold 和验证样本；
4. 完整的外层 5×5 结果（25 折），且每折预测可重算指标。

这些条件不满足时，哪怕某一方 R² 或 RMSE 更漂亮，也只能称为背景趋势，不能称为严格优于。尤其不能把 `SM-static-4620` 与 `SM-OHE-5760`、不同数据集、不同收率尺度或不同切分的均值混在同一排名中。

### 四项指标的总览

设验证折有 `n` 条反应，真实收率为 `y_i`，模型预测为 `ŷ_i`，误差为 `e_i = y_i - ŷ_i`。以下以收率已经按百分数表示为例；若输入标签是 0–1 小数，RMSE/MAE 的单位也就是“收率小数”，不是百分点。

| 指标 | 它主要问什么 | 理想方向 | 单位 / 范围 | 本轮正式比较中的角色 |
| --- | --- | --- | --- | --- |
| RMSE | 有没有出现较大的预测失准 | 越低越好 | 与收率相同的单位 | **主指标** |
| MAE | 一条普通反应平均会偏多少 | 越低越好 | 与收率相同的单位 | 互补：检查典型误差 |
| R² | 比“只猜该折平均收率”好多少 | 越高越好 | 无单位，通常不超过 1，可为负 | 互补：检查相对基线解释度 |
| Kendall τ | 高低收率反应的排序是否正确 | 越高越好 | -1 到 1 | 互补：检查排序能力 |

后面三项都很重要，但在当前已预注册的 RF–AutoGluon 5×5 比较中，**“显著更好”的正式判断以折级 RMSE 为主**。MAE、R²、Kendall τ 是必须同时查看的反向证据和解释材料；它们不能被忽略，也不应临时改成主指标来挑选对某模型有利的结果。

## Q&A 记录

### 回归建模指标

**Q：** RMSE、R²、MAE、Kendall τ 分别是什么意思？在 YONOD 的收率预测报告里应怎么看？

**A：** 可以把一次模型预测想成“根据反应条件，猜这条反应能得到多少收率”。四项指标从四个角度检查这次猜测。

#### 1. RMSE：对“大错”特别敏感的主误差指标

公式为：

```text
RMSE = sqrt(平均(e_i²))
```

先把每条误差平方、再平均、最后开根号。平方的作用是：20 个百分点的失准不只算作两个 10 个百分点失准，而会被额外放大。因此 RMSE 很适合把“模型是否会给实验带来严重误导”放在首位的情形。

例如真实收率为 `[70, 80, 90]`，预测为 `[72, 76, 90]`。误差是 `[-2, 4, 0]`（正负号只表示高估或低估）：

```text
MAE  = (2 + 4 + 0) / 3 = 2.00 个百分点
RMSE = sqrt((2² + 4² + 0²) / 3) = 2.58 个百分点
```

这里 RMSE 大于 MAE，是因为那条错 4 个点的反应被平方后更受重视。若 5×5 外层验证报告 `RMSE = 6.13 ± 0.72`（示意格式），应读作：在重复划分中，一个验证折的均方根收率误差约为 6.13 个目标单位，折间波动约 0.72；它**不是**“有 6.13% 的概率出错”。

本项目把 RMSE 定为主指标有三层原因：它保留收率单位、对严重偏差敏感、并且当前严格成对检验与 Holm 多重校正均围绕 25 个外层折的 RMSE 差值预先定义。比较 AutoGluon 和 RF 时，定义 `ΔRMSE = RMSE_AG - RMSE_RF`；负值表示 AG 的误差较低。

**局限**：RMSE 会被少数极端反应主导。若一个模型多数样本很准、但少数反应错得很离谱，RMSE 会严厉惩罚它；这不是错误，而是它的价值取向。因此必须同时看 MAE。

#### 2. MAE：一条“典型反应”会偏多少

公式为：

```text
MAE = 平均(|e_i|)
```

它只取绝对值后平均，不平方。仍用上例，MAE 为 2.00 个百分点，直觉含义就是“随机抽一条验证反应，预测通常离真实收率约 2 个点”。它通常比 RMSE 更容易和实验人员沟通。

MAE 与 RMSE 的分歧很有诊断价值。例如两个模型在四条反应上的绝对误差分别为：

| 模型 | 绝对误差 | MAE | RMSE | 解读 |
| --- | --- | ---: | ---: | --- |
| A | `[0, 0, 0, 10]` | 2.50 | 5.00 | 大多数很准，但有一次严重失准 |
| B | `[3, 3, 3, 3]` | 3.00 | 3.00 | 每次都略有偏差，但没有灾难性错误 |

若只看 MAE，会偏向 A；若担心低收率/高收率误判带来的实验风险，RMSE 会偏向 B。当前正式规则仍以 RMSE 决定主结论，但这种 MAE–RMSE 冲突应标记为“证据不完全一致”，不能轻描淡写地写成“全面更强”。

#### 3. R²：相对于“只猜平均收率”的解释度

公式为：

```text
R² = 1 - [Σ(y_i - ŷ_i)²] / [Σ(y_i - ȳ)²]
```

分母是该验证折中真实收率围绕其平均值的自然波动；分子是模型的平方误差。因此 R² 问的是：模型比“完全不看反应条件，只猜这个验证折平均收率”节省了多少平方误差。

在前述 `[70, 80, 90] -> [72, 76, 90]` 的例子中，平方误差为 `20`，真实值围绕均值 80 的平方波动为 `200`，所以 `R² = 1 - 20/200 = 0.90`。这表示模型相对于均值基线解释了约 90% 的该折变异，不等于“90% 的单条预测正确”。

- `R² = 1`：所有预测完全准确。
- `R² = 0`：和只猜该折平均收率一样好。
- `R² < 0`：还不如只猜该折平均收率；这在严格外部验证中是允许且有意义的，不是程序必然出错。

**为什么 R² 不能单独决定优劣**：它依赖真实收率在该折本身有多分散。不同数据集、不同收率范围、甚至不同外层折的 R² 不能直接按绝对值横比。对同一验证样本，RMSE 和 R² 都由平方误差决定，方向通常一致；若汇总后两者明显冲突，常见原因是每折目标波动不同、做的是“先逐折计算再平均”、样本总体不同，或聚合口径不一致，应先审计而不是任选一个结果。

#### 4. Kendall τ：模型有没有把反应按高低收率排对

Kendall τ 不直接关心“预测是 73 还是 75”，而看任意两条反应的相对顺序。例如真实收率 A 高于 B，模型也预测 A 高于 B，这一对就是排序一致；反过来就是排序不一致。τ 近似反映一致对比不一致对的净优势；本轮脚本调用 `scipy.stats.kendalltau`，使用其默认的、可处理并列值的计算，并保存 τ 是否可定义及其原因。

- `τ = 1`：所有可比较反应对的高低顺序都对。
- `τ = 0`：排序与真实高低没有稳定关联。
- `τ = -1`：排序完全颠倒。

它特别适合“先按预测收率挑最值得实验的候选，再做少量实验”的筛选任务。可是它不检验数值是否校准：真实 `[70, 80, 90]`，预测 `[50, 60, 70]` 的 τ 仍为 1，因为顺序完美；但 MAE 和 RMSE 都是 20 个点，R² 为 -5，显然不能把它称为可靠的收率定量预测器。

反过来，若真实值非常接近，例如 `[80.0, 80.1, 80.2]`，预测为 `[80.2, 80.1, 80.0]`，MAE 约为 0.13、RMSE 约为 0.16，却把顺序完全翻转（τ = -1）。这说明数值误差虽小，若目标是细微排序或候选筛选，模型仍可能不适用。真实值或预测全相同、可比较对不足等情况会使 τ 未定义；报告必须保留 `kendall_tau_defined` 和原因，不能把空值当成 0。

脚本还会保存 τ 的 p 值。它检验的是“该折的 τ 是否与 0 有区别”，**不是**“该模型是否显著优于另一个模型”的正式 p 值。模型优劣仍须在同一外层折上比较成对差值，并处理重复交叉验证折之间的相关性。

### 四个指标相互矛盾时，应该怎样说

下表是报告解读的安全语言。它强调“解释冲突”，而不是把冲突掩盖为一个总分。

| 观察到的模式 | 可能含义 | 合适的结论 |
| --- | --- | --- |
| RMSE↓、MAE↓、R²↑、τ↑ | 数值误差、基线解释度、排序均向好 | 证据一致；仍需通过同折统计与多重校正才可称显著更好 |
| RMSE↓、MAE↑ | 少数大错减少，但典型误差可能增加 | 主指标改善，辅助证据冲突；检查误差分布 |
| RMSE↓、R²↓ | 常见于不同折/总体或按折平均后的目标方差差异 | 先核对同一验证样本与聚合口径；不能直接声称全面更强 |
| RMSE↓、τ↓ | 数值更接近真实，但高低排序更差 | 对定量回归有利，对实验候选排序未必有利；标为 mixed evidence |
| τ↑、RMSE/MAE↑ | 排序更好但校准更差 | 可考虑用于粗筛选，不应直接用于报出精确收率 |
| R² 很高但 RMSE 也大 | 数据集收率范围很大，模型相对基线好但绝对误差仍可能不可接受 | 同时报告收率单位的 RMSE/MAE，不只报 R² |

### 推荐的报告优先级

这个优先级是本轮“模型是否优于 RF”的研究规范，而不是所有化学机器学习问题永恒不变的唯一排序：

1. **先报告可比性和完整性**：数据总体、描述符、外层折、完成数、OOF 是否完整。没有这一步，任何指标排序都不可靠。
2. **以 RMSE 作主结论**：每个模型/组合报告 25 折 `mean ± std`；同描述符下用配对的 `ΔRMSE`、不确定性区间、相关性校正的重复 5×5 检验和 Holm 校正决定 `supported / mixed / not_supported`。
3. **同时列 MAE 与 R²**：MAE 解释典型收率偏差和异常值影响；R² 解释相对均值基线的改善。两者不要求机械地与 RMSE 同方向，但反向时必须说明。
4. **同时列 Kendall τ**：作为排序能力检查。若项目改为“只选前若干候选做实验”，τ 的业务权重可以升高；但不能因此忽略收率绝对误差。
5. **最后才讨论均值与标准差**：`mean` 是跨折的典型性能，`std` 是对切分变化的敏感度。小标准差表示较稳定，不自动表示较准确；大标准差提示结论对数据划分敏感。

在当前正式的 11 个 AutoGluon–RF 单元中，RMSE 的 11 项主比较做 Holm 校正。MAE、R²、Kendall τ 应分别作为辅助/探索性证据报告，不能把它们与 RMSE 的 p 值混成一个“显著性”。只有 RMSE 方向、校正后统计和辅助指标没有系统性强反向证据时，才可以写“该数据集–描述符组合中 AutoGluon 相比 RF 得到支持”。单个最佳单元、只看均值、或只挑一项指标，都不足以证明“AutoGluon 普遍远强于 RF”。

### 阅读一行 YONOD 结果的实用模板

假设同一数据集、同一 SOAP 特征、同一 25 个外层折给出：

```text
RF:          RMSE 7.23 ± 0.80, MAE 4.90 ± 0.55, R² 0.92 ± 0.02, τ 0.81 ± 0.04
AutoGluon:   RMSE 6.13 ± 0.70, MAE 4.35 ± 0.42, R² 0.94 ± 0.02, τ 0.86 ± 0.03
```

正确阅读顺序是：AG 的主误差少约 1.10 个收率单位；典型绝对误差、相对均值基线的解释度和排序也同步改善；接着还需看 25 个**成对** `ΔRMSE` 是否经相关性修正和 Holm 校正后支持改善。通过后，可以称这个“数据集–SOAP”单元支持 AG；仍不能自动外推到其他描述符、其他数据集或 OHE 的不同总体。

若同样的数值中 τ 反而从 0.81 降到 0.65，写法应改为：“AG 在 RMSE/MAE/R² 上更好，但排序能力下降，证据混合；是否采用取决于任务是定量预测还是候选筛选。”这正是四指标并存的意义。
