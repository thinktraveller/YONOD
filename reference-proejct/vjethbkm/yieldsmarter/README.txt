# Data and software for the paper "Yield Smarter, Not Harder: Good Practices for Machine Learning of Reaction Outcomes"

- yieldsmarter.yml : conda environment file to construct an environment for reproducing the results
- Data/ : source structural and activity data, xyz files for the conformers used for SOAP descriptors
- Src/ : python files for generating descriptors, building and validating ML models, and constructing some of the plots
- Results/ : generated descriptors and results from model validation
